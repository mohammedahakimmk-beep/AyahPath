Installation

How to install on Android

The APK is an Android app. Follow these steps to install it safely. (We do not publish to the Play Store yet — this is a direct APK.)

1

Download the APK

Tap the "Download APK" button above. If it doesn't start automatically, tap the button again and choose "Save".

2

Open the file

Open your Downloads folder (or notifications) and tap app-release.apk.

3

Allow installs

Android will warn about installing from unknown sources. Tap Settings → allow "Install unknown apps" for your browser or file manager.

4

Install & open

Tap Install, then Open. If prompted, tap "Install anyway" for the Play Protect notice.

🛡️ Quick troubleshooting

  • "App not installed" → make sure you downloaded the whole file (check size, should be ~50 MB+) and delete old attempts.
  • "Didn't start download" → long-press the download button and choose "Download linked file", or open the site in Chrome.
  • Play Protect warning → this is normal for direct APKs; tap "More details" → "Install anyway".
  • Updates → the app checks for updates on launch. If an update is required, you'll be prompted to download it—your data is preserved.
